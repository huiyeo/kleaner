# Kleaner v1.1.0 — 扫描提速与冻结修复

> 相对 v1.0.0 的性能与稳定性版本，附带规则治理维护机制。完整路线见 `docs/goals.md`。

## 本版本要点

- **真实目录扫描大幅提速**：修复扫描器三重系统调用放大（逐条目补查 reparse point、逐目录双次枚举、逐文件补 stat），真机全规则扫描实测 97.6s → 2.5s，逐规则结果与优化前一致。
- **修复清理时界面冻结（AppHang）**：清理计划构建内部会完整重扫所选规则，此前在 UI 线程同步执行，规则多、目录大的机器上点击「清理」后整个窗口无响应；现移至后台线程，确认框即点即出。
- **隔离区窗口操作异步化**：还原 / 清空批次 / 清空过期批次改为后台执行并按操作互斥禁用按钮；补上清单缺失或损坏时的界面层兜底（不再以崩溃收场）。
- **规则治理维护机制**（rule-governance 06）：规则库 101 条全量标注维护责任（`maintainer`）与证据更新时间（`lastEvidenceCheck`），治理报告新增维护统计与证据超龄（>180 天）警告，非法日期严格解析 fail-closed。

## 质量证据

- 完整测试 221/221 通过（Release 0 警告 0 错误）；新增隐藏/系统文件参与匹配、目录联结不深入、枚举属性一致性三个回归用例。
- 性能口径：真机测量与优化前后对照见 `docs/performance-baseline.md`（2026-09-11 节）。

## 已知边界（如实声明）

- **应用内自动更新未接线**：升级路径=手动运行新版 Setup.exe 覆盖安装（用户数据与隔离区不受影响）。
- **规则更新签名信任**：设置页的规则更新为「用户输入 URL + SHA512」，不构成发布方身份认证；官方签名清单通道见 `rules-channel` 分支。
- **应用未签名**：首次运行触发 SmartScreen「未知发布者」提示，属未签名应用正常现象，点「更多信息→仍要运行」。
- **SLO 重新冻结待执行**：扫描引擎优化后，`docs/performance-baseline.md` 冻结表不再反映当前引擎（含峰值内存口径异常记录），重新冻结需两次同参数独立复跑。
