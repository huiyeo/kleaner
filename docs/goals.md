# Kleaner 长期目标（无人值守推进的北极星）

> 本文档是无人值守会话的行动授权与边界。任何 Agent 在自主推进本项目前必须先读完本文档与 `AGENTS.md`，两者冲突时 `AGENTS.md` 的安全条款优先。

## 北极星

成为 Windows 上最可审计的 C 盘清理工具：只清理"能说清为什么安全"的东西——每条规则可溯源、每次删除可还原、每个入口（GUI/CLI）可验证。

## 自主推进规则

1. **一次只做一张工单**：构建 + 测试全绿、按 `docs/conventions.md` 提交后，才开始下一张。大目标先拆票（沿用三张工单的格式：What to build / Blocked by / Status / checklist）。
2. **卡点即停**：需求歧义、与安全红线冲突、需要真实机器验证删除路径——把该工单 Status 改为 `blocked`，在文末写明原因与所需输入，转下一张；不得强行产出。
3. **安全红线（不可协商）**：不在真实系统上执行清理或删除操作（测试一律用注入的临时目录）；不触碰真实注册表与真实启动目录；不改动 `docs/deletion-path.md` 描述的删除安全语义；`git push` 仅限快进推送，永不改写历史、永不 force。
4. **收尾动作**：更新工单复选框；在本文档「进度记录」追加一行（日期 + 干了什么 + 下一步）；代理可用则推送，不可用则不重试超过 2 次，留待下次运行补推。
