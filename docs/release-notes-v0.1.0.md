# Kleaner v0.1.0 — 首个公开版本

白名单制的 Windows C 盘清理工具：只清理"能说清为什么安全"的东西。

## 安全模型

- **严格白名单**：只有规则库中明确列出的类别才可清理，每条规则附带安全性说明（界面内可查看"为什么这条规则是安全的"）
- **年龄阈值**：默认仅清理 14 天未修改的文件（缓存类 7 天）；更新器残留按版本规则保留最新一份
- **强制预览**：启动即扫描（只读），清理前显示"将删除什么、每类多少"，二次确认后才执行
- **隔离区可还原**：删除即移入隔离区（默认在剩余空间最大的非系统盘），保留 7 天，期间一键整批还原；原路径有同名文件时绝不覆盖
- 引擎层固定排除云盘占位文件（OneDrive 等 reparse point）；被占用文件跳过并在报告中列出

## 功能

- 12 条内置规则：用户/系统临时目录、Chrome/Edge 缓存、npm/pip 缓存、5 款应用更新器残留、Windows 更新下载残留
- 高级模式（引导操作，不直接改动系统）：WSL 虚拟磁盘检测与压缩指引、休眠/系统还原点/WinSxS 跳转系统工具、注册表卸载残留**只读**扫描
- 规则库外置 + 在线更新（SHA512 + 语义校验双闸门）

## 安装

- **安装版**：下载 `Kleaner-win-Setup.exe` 双击安装（用户级，无需管理员）
- **便携版**：下载 `Kleaner-win-Portable.zip` 解压即用

> 应用未做代码签名，首次运行如遇 Windows SmartScreen 提示"未知发布者"，点击"更多信息 → 仍要运行"即可。安全模型的核心（规则可审计 + 删除可还原）不依赖签名信任。

## 系统要求

Windows 10 1809+ / Windows 11 x64。安装版与便携版均为自包含单文件，**无需安装 .NET 运行时**。

## 已知边界（诚实声明）

- 本版本未验证软件的无限多样性：规则面向常见 Electron 应用更新器与官方文档明确的缓存目录；如遇规则误伤，请提 issue 并附规则 id（隔离区可完整还原，不影响排查）
- 注册表清理仅"扫描展示"，不提供删除（观察社区反馈后再决定）
- 自动定期清理未实现（故意不做：自动+删除的组合放大事故面）
