# 术语表

Kleaner 的领域词汇。**只定义词，不描述实现**——实现细节见 `architecture.md`、`rules.md`、`deletion-path.md`。

首次出现时若与直觉不符，以本表为准。

---

## 规则域

**规则（rule）**
白名单里的一条清理条目。全系统的清理权限都来自规则，规则之外没有任何东西会被清理。

**类别（category）**
规则的六个分类之一：`temp`、`browser-cache`、`dev-cache`、`updater`、`system`、`application`。
*歧义*：它不只是展示标签——它还决定该规则缺省的年龄阈值，且同一组词同时用作 UI 展示名。

**风险等级（risk）**
`low` 或 `medium`。schema 层没有第三档。
*易错*：它**只影响界面显示**，当前不参与任何执行分支。真正影响"是否默认勾选"的是 `verified`，不是 `risk`。

**验证状态（verified）**
一条规则是否已真机实测的自由文本声明。
*易错*：它有行为——以"本机实测"开头的规则才默认勾选，其余默认不勾选并标注。这与"风险等级"容易混淆，二者语义不重叠。

**路径模式（paths）**
规则命中文件的绝对路径模式，以环境变量或盘符开头。`*` 匹配单段路径，`**` 跨任意层级。

**排除（exclude）**
从命中结果中剔除的路径模式，优先级高于 `paths`。

**年龄阈值（ageDays）**
只清理最后修改时间早于 N 天的文件。取值逐级回退：规则级 → 分类默认 → 全局默认。

**保留最新（keepNewest）**
按修改时间保留最新的 N 份，其余清理。**设置了它就豁免年龄阈值**——两者互斥。

**安全说明（safetyNotes）**
每条规则的"为什么安全"：目录用途、删除影响、验证方式。是规则库可审计性的载体。

**安全文档锚点（safetyDoc）**
指向 `rules/docs/safety-notes.md` 中对应条目的锚点。

**需要提权（requiresElevation）**
该规则是否需 UAC 提权后才执行。
*歧义*：启动项领域有一个同名概念，指该项位于 HKLM 需要管理员权限——两者不是一回事。

## 执行域

**隔离区（quarantine）**
被"清理"的文件的去处。Kleaner 的"删除"实为移入隔离区，可还原。
*关键认知*：产品内不存在永久删除这一动作。

**批次（batchId）**
一次清理操作产生的隔离区批次，一次清理一个批次，还原以批次为单位。

**清单（manifest）**
批次目录内记录"文件原来在哪"的 JSON，是还原的唯一依据。

**还原（restore）**
*歧义，两个独立概念*：
1. 隔离区还原——把批次移回原路径，遇同名文件改名而不覆盖。
2. 启动项还原——按备份重建注册表值或启动文件夹文件。

**操作历史（history）**
只追加的审计流水，记录每一次删除、还原、清空。可回溯。

**预览（dry-run）**
只展示"将要清理什么、每类多少"，不实际动手。CLI 的默认行为；GUI 的启动即扫描 + 二次确认。

**重解析点（reparse point）**
OneDrive 等云盘的占位文件、目录联结。引擎层一律排除，规则里无需声明。

**提权（elevation）**
UAC 相关。规则领域指整进程重启提权；启动项领域指调 `reg.exe` 修改 HKLM。

## 产品域

**扫描（scan）**
*歧义，三义*：
1. 规则白名单扫描——按规则库枚举可清理文件（主力路径）。
2. 工具箱任意目录只读扫描——大文件、重复文件、空间占用。
3. 注册表卸载残留只读扫描——高级模式内。

**清理（clean）**
把命中文件**移入隔离区**。注意不是删除。
*歧义*：CLI 里必须 `--apply` 才动手，GUI 里没有等价开关、代之以二次确认。两者最终落到同一个隔离区入口。

**大文件 / 重复文件 / 空间分析（large-files / duplicates / usage）**
工具箱三个只读能力。
*易错*：`usage` 在 CLI 里既是子命令，也是打印帮助的内部函数名。另前两者在 GUI 中被当作伪规则 id 塞进隔离区清单和历史。

**矩形图（treemap）**
空间分析的可视化形态，按文件/目录大小铺矩形。

**启动项（startup）**
随 Windows 登录自启的项，来自注册表 Run 键与启动文件夹。
*歧义*：也指启动文件夹这个目录本身。

**高级模式**
引导型功能集合（WSL 压缩、系统大件、注册表残留）。**只扫描与指引，不直接改动系统项**。

**工具箱**
大文件、重复文件、空间分析三件套的窗口。只读扫描，清理一律进隔离区。

## 悬空词

以下词在 schema 里存在，但代码从不消费。遇到时不必寻找其作用：

- `lockedFilePolicy`——schema 声明，C# 模型无对应字段，行为硬编码在隔离区移动逻辑里。
- `channel`——规则文件里有值，加载器从不读取。

## 本表不存在但可能被误用的词

- **workspace**——代码库中不存在此术语。不要引入。
