> 依据 `docs/goals.md` Phase 4：「仅评估不会破坏普通用户主流程、安全宪法和性能预算的能力。任何新功能先证明与"安全释放空间"的核心任务直接相关。」

> 结论分级：**候选**（可进入实施拆票）/ **排除**（宪法或定位冲突，附条款依据）/ **观察**（需所有者决策）/ **已覆盖**（现有能力）。

## 评估标准（goals.md 原文对照）

1. **直接相关性**：与「安全释放空间」的核心任务直接相关，而非泛「系统优化」。
2. **主流程**：不干扰「安全扫描」唯一主动作；次级入口收纳。
3. **安全宪法**：尤其第 8 条明确不做清单（注册表清理/驱动更新/内存加速/后台自动清理/系统组件强制删除/绕开隔离区的清理）；高风险系统项只读分析或引导至 Windows 官方工具。
4. **性能预算**：不影响 SLO（冻结表见 `docs/performance-baseline.md`；2026-09-11 扫描引擎优化后该表待重新冻结，引用其数字须连同该文件的时效说明）；同一磁盘不并发重型遍历。

## 现有能力盘点（避免重复评估）

- 主流程：白名单规则扫描→确认→隔离区（101 条规则全部已验证；六类别 application 40 / dev-cache 31 / browser-cache 15 / updater 7 / system 6 / temp 2）
- 工具箱（只读）：空间分析 + 矩形图、大文件、重复文件
- 高级模式（引导式，Kleaner 不直接改动系统项）：WSL 虚拟磁盘压缩指引、注册表残留只读展示、**系统大件引导（`SystemToolGuide`）：关闭休眠 powercfg /h off、系统还原点管理、WinSxS 组件存储清理 DISM StartComponentCleanup（不带 /ResetBase），均已含警示与可逆说明**
- 启动项管理（禁用/还原，非删除）；隔离区（还原/删除/7 天清空）；历史审计；AI 解释预览（Phase 3）

## 候选评估

### 引导式候选（符合第 8 条「引导官方工具」形态，走高级模式框架）

#### B1. 休眠文件 hiberfil.sys（关闭休眠/快速启动）— 已覆盖（2026-09-11 复核修正）

> **修正**：初版评估误列为候选。复核 `src/Kleaner.SpecialOps/SystemToolGuide.cs` 确认：高级模式「系统大件」Tab 已实现 powercfg 引导（含可逆说明与快速启动失效警示），形态与本节建议一致。下述分析保留作背景。

- 相关性：直接。笔记本/台式机常见 3–13 GB（约物理内存 40–100%）。
- 形态：只读检测 `C:\hiberfil.sys` 存在与大小 → 高级模式展示 → 引导微软官方命令 `powercfg /h off`（复制到剪贴板，用户自执行）。**可逆**（`powercfg /h on`）。
- 宪法：✅ 不直接改动系统；官方命令；展示可逆性与副作用（快速启动失效、笔记本合盖休眠不可用）。
- 性能：单文件存在性检测，零遍历。
- 风险：副作用警示必须同屏展示；不满足「不破坏用户预期」时仅展示不推荐。

#### B2. WinSxS 组件存储清理（DISM StartComponentCleanup）— 已覆盖（2026-09-11 复核修正）

> **修正**：初版评估误列为候选。`SystemToolGuide` 已实现 `Dism.exe /Online /Cleanup-Image /StartComponentCleanup` 引导（不带 /ResetBase，保留更新卸载能力；含 10–30 分钟不可中断警示），与本节边界完全一致。下述分析保留作背景。

- 相关性：直接。WinSxS 常占 5–15 GB，官方维护操作可回收部分。
- 形态：高级模式引导 `Dism.exe /Online /Cleanup-Image /StartComponentCleanup`（官方命令、复制执行）。
- 宪法：✅ 与第 8 条「系统组件强制删除」的边界：**仅引导不带 `/ResetBase` 的官方维护命令**（保留已装更新的卸载能力）；「强制删除」不做。引导式，Kleaner 不执行。
- 风险：操作耗时 10–30 分钟且不可中断——指引中必须前置警示；失败提示引导至官方文档。

#### B3. Windows.old 旧系统安装残留 — 已实施（2026-09-11，工单 `.scratch/phase4/issues/02-b3-windows-old.md`）

- 相关性：直接。动辄 20–50 GB。
- 形态：只读检测 `C:\Windows.old` 存在与大小 → 提示存在 → **引导至 Windows 官方路径**（设置 > 系统 > 存储 >「临时文件」>「以前的 Windows 安装」，或磁盘清理 cleanmgr）。Kleaner 不提供删除入口。
- 宪法：✅ 删除即丢失系统回滚能力，属高风险系统项 → 第 8 条「只读分析或引导至 Windows 官方工具」逐字适用。
- 风险：官方删除同样有 10 天回滚窗口限制——提示以官方 UI 文案为准，Kleaner 不自行表述期限。
- 实施形态：高级模式「Windows.old」Tab——加载即零遍历存在性检测（reparse point 排除与引擎同纪律）；占用测量为显式触发的有界流式枚举（上限 20 万文件、截断显式提示）；官方入口仅打开 ms-settings 存储页与 cleanmgr，删除动作与期限提示全部发生在官方界面内。

### 规则库扩张候选（走既有验证→签名更新流程，非新功能）

#### K1. 系统内存转储 — 已实施（2026-09-12，工单 `.scratch/phase4/issues/04-k1-memory-dump.md`）

- 相关性：直接。`C:\Windows\MEMORY.DMP`（可达数百 MB–数 GB）与 `C:\Windows\Minidump\`。
- 宪法：✅ 调试数据非用户数据；需管理员（requiresElevation 已支持）；进隔离区可还原。
- 实施：规则 `kernel-dumps`（`%SystemRoot%\MEMORY.DMP` + `%SystemRoot%\Minidump\**`，ageDays 继承 system=14）。本机核实路径可达性并验证未提权扫描行为（0 命中无异常）；**命中与删除场景本机无转储样本可测，verified 诚实标注「官方文档来源，本机未验证，默认不勾选」**，待有真实转储的机器补验转正。规则库随附（103 条），签名清单 v1.1.0 已本地演练，渠道发布待所有者确认。

#### K2. 传递优化缓存 — 已实施（2026-09-12，工单 `.scratch/phase4/issues/03-k2-delivery-optimization.md`）

- 相关性：直接。Windows 更新 P2P 分发缓存（Win11 现行位置 `C:\Windows\ServiceProfiles\NetworkService\...\DeliveryOptimization\Cache`，旧版位置 `C:\Windows\SoftwareDistribution\DeliveryOptimization\Cache`），与已验证的「Windows 更新下载残留」路径不相交。
- 宪法：✅ 官方缓存语义，重建无害；官方 Delete-DeliveryOptimizationCache / 存储感知 / 磁盘清理为同类对象。
- 实施：规则 `delivery-optimization-cache`（两位置 `Cache\**`，requiresElevation=true，ageDays 继承 system=14）。本机核实：现行位置未提权 ACL 拒绝访问、旧版位置不存在；未提权扫描 0 命中无异常。**提权可达性与实际清理场景待真机验证窗口，verified 诚实标注「官方文档来源，本机未验证，默认不勾选」**。规则库随附（103 条），签名清单 v1.1.0 已本地演练，渠道发布待所有者确认。

### 排除（宪法/定位冲突，记录依据防止后续重复提案）

| 候选 | 结论 | 依据 |
|---|---|---|
| A. 清空回收站 | **排除** | 回收站是用户显式删除缓冲，清空=绕开 Kleaner 隔离区的永久删除 → 宪法第 8 条「绕开隔离区的清理」。只读展示回收站占用可由空间分析承担（已覆盖）。 |
| E. 存储感知/定期自动清理 | **排除** | 宪法第 8 条「后台自动清理」明确不做；与第 3 条强制预览确认冲突。 |
| F. Cookie/登录状态/表单清理 | **排除** | 非垃圾（数据丢失风险大、占用小）；现有「仅 HTTP 缓存与代码缓存」是正确边界。 |
| G. 注册表清理 | **排除** | 宪法第 8 条明确不做；现有注册表残留**只读展示**已是边界内形态。 |
| I. 下载目录清理 | **排除** | 用户文件非垃圾；北极星「诊断结果不自动获得清理资格」。已有保守规则（下载目录残留分块缓存）覆盖可验证子集。 |
| J. OneDrive Files On-Demand 释放 | **排除** | 影响用户文件可用性；未来仅可做只读占用展示。 |
| M. 微信/QQ 接收文件目录 | **排除** | 用户文件（聊天记录）；规则库已覆盖其缓存/日志子集。 |
| R. 应用卸载残留扫描 | **排除/远期** | 「孤儿目录检测」需注册表卸载项对照+启发式判定，脱离白名单制（固定路径+版本化规则）；误判率高。若未来做，先立 ADR。 |
| O. 云端 LLM / 内置模型 | **排除** | ADR 0004 已裁决（隐私宪法/不内置不自动下载）。 |
