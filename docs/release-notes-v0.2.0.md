# Kleaner v0.2.0 — 工具箱与操作历史

参照 [MangoDisk](https://github.com/harry0703/MangoDisk) 的安全方法论与功能设计进行的升级。

## 新增

- **操作历史**：每次删除类操作（清理/还原/清空）自动记录到 `history.jsonl`（时间、对象、文件数、大小、结果），界面"历史"窗口可审计——补齐"扫描只读、删除确认、操作可回溯"三段式契约的最后一环
- **CLI 安全契约**：`clean` 命令默认 dry-run，`--apply` 才执行，非交互环境必须再显式 `--yes`（否则退出码 2 拒绝）；`large-files`/`duplicates`/`usage` 只读子命令；全部支持 `--format json`
- **工具箱**（新窗口）：
  - 大文件清理：全目录扫描 → 人工勾选 → 移入隔离区
  - 重复文件清理：按内容指纹（大小预筛 → 首块哈希 → 全量 SHA256）查重，每组默认保留最新一份，其余进隔离区
  - 空间分析：目录占用排行，支持逐级下钻（只读）
- **规则库扩至 20 条**（开发者机器全景）：uv 缓存、Playwright 浏览器二进制（394 MB 实测）、Cargo/Go/Gradle/Maven 缓存、崩溃转储、Windows 错误报告队列。每条规则标注验证状态（本机实测 / 官方文档来源），未真机验证的诚实声明

## 安全设计（不变量）

白名单制、年龄阈值、强制预览、隔离区可还原、reparse point 排除——全部保持；新增功能（大文件/重复文件清理）同样只进隔离区，绝不直接删除。

## 安装

同 v0.1.0：`Kleaner-win-Setup.exe`（安装版）或 `Kleaner-win-Portable.zip`（便携版），自包含免装 .NET。未签名应用首次运行请点 SmartScreen"仍要运行"。
