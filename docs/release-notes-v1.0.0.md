# Kleaner v1.0.0 — 可信的 v1 核心

> Phase 0（证明安全宪法不可绕过）与 Phase 1（可信的 v1 核心）全部验收收口的版本。完整路线见 `docs/goals.md`。

## 本版本要点

- **白名单清理 + 隔离区可还原**：只清理规则库中「能说清为什么安全」的条目；删除即移入隔离区，7 天内可整批还原。
- **强制审计与事务隔离**：预写/原子 manifest、逐项状态、待补记凭据崩溃恢复；历史记录带哈希链（篡改可发现，检测非预防）。
- **移动路径句柄锚定**：清理/还原移动的检查-移动间隙由目录句柄锚定关闭（RFC 级对抗验收）。
- **官方签名规则更新**：规则清单经 Ed25519 签名（RFC 8032 验证），拒绝降级、篡改与未签名清单；设置页可一键检查更新。
- **高级能力**：启动项管理（禁用前自动备份）、WSL 磁盘检测与压缩指引（只引导）、注册表卸载残留只读扫描。
- **性能 SLO（测量机范围冻结）**：冷启动热缓存 p95 <2s、取消停止 ≤2s、扫描进度 ≤1s、典型规则扫描 p95 <15s（合成数据集口径，详见 `docs/performance-baseline.md`）。

## 质量证据

- 完整测试 189/189 通过（Release 0 警告 0 错误），覆盖成功/失败/取消/部分成功/损坏输入/恢复路径。
- 端到端验收：GUI 与 CLI 主流程全链（扫描→解释→确认→隔离→还原→历史）真机走查通过。
- 安装矩阵：全新安装/覆盖升级/升级中断/卸载真机验证通过（回退见下方已知限制）。

## 已知边界（如实声明）

- **回退**：真机验证通过（v1.0.0 ↔ 0.3.1 双向覆盖安装：重装 0.3.1 启动正常，1.0.0 写入的数据——哈希链 head/官方规则/历史——完整保留可读）。
- **断电**：掉电场景为置信论证级（全部关键写入 WriteThrough+原子替换），无 VM 硬断电实测。
- **凭据来源认证**：同权限本地进程可伪造本机数据是已知边界（ADR-0002），历史哈希链为检测非预防。
- **应用未签名**：首次运行触发 SmartScreen「未知发布者」提示，属未签名应用正常现象，点「更多信息→仍要运行」。
