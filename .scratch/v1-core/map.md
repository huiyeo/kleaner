## Notes

Phase 1 的完成定义（goals.md 原文，四条）：

1. 极简安全扫描、解释、预览、确认、隔离、还原、历史和官方规则更新形成完整主流程。
2. 通过已冻结的性能 SLO、Windows 11 x64 真机矩阵和 UI 可读性/无障碍验收。
3. Kleaner 自身安装、升级、回退和卸载稳定；不建设第三方软件卸载器。
4. 启动项、WSL、注册表残留等高级能力不因已经存在就自动成为 v1 可靠性承诺，须独立验收后才能转正。

主流程的大部分构件已在 Phase 0 落地（扫描/预览/确认/隔离/还原/历史/官方签名规则更新），Phase 1 的重心是**验收与稳定**，不是新功能。

- 无障碍验收（高对比度主题、屏幕阅读器）在电脑操作环境下的可验证深度未知。
