# 03: UI 可读性与无障碍验收

**What to build:** goals.md Phase 1 验收项：中文界面在 100%/125%/150% 缩放下文字完整；支持键盘、高对比度、清晰焦点，状态不只依赖颜色表达。

**Blocked by:** None（与 01 并行可行，但建议 01 之后执行以复用应用启动路径）。

**Status:** ready-for-agent

- [ ] 100%/125%/150% DPI 缩放下 7 个窗口文字完整不裁切（电脑操作逐窗口截图/树取证）
- [ ] 键盘可达性：Tab 顺序覆盖全部可操作控件，主按钮可回车触发，Esc 关闭对话框
- [ ] 焦点可见性：键盘导航时焦点框清晰可见
- [ ] 高对比度模式：Windows 高对比度主题下界面仍可辨认（不要求美观，要求可读）
- [ ] 状态不依赖颜色：错误/警告/成功状态有文字或图标冗余（隔离区提示条、历史完整性提示、扫描状态栏）
- [ ] 发现的问题逐项立票或当场修复
- [ ] 验收记录写入 Comments

**边界：** 屏幕阅读器（Narrator）走查尝试但不作为通过条件——自动化环境对其支持深度未知，如实记录即可。
