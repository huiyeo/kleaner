# 04: 高级能力 v1 转正/排除决定

**What to build:** goals.md Phase 1 第 4 条：启动项、WSL、注册表残留等高级能力不因已经存在就自动成为 v1 可靠性承诺，须独立验收后才能转正。本票对三项能力逐一验收并决定「转正为 v1 承诺」或「显式排除出 v1 声明」。

**Blocked by:** None。

**Status:** ready-for-agent

- [ ] **启动项**（StartupManager）：枚举/禁用/还原往返已有 CLI `startup-test` 自检（写真实注册表与启动文件夹）——审查该自检的覆盖面，真机走查 HKCU 路径与回滚路径，决定转正或排除（含「需提权的 HKLM 路径」边界声明）
- [ ] **WSL vhdx**（WslInspector）：检测+压缩指引是引导型能力，验证检测准确性与指引文案正确性（不实际压缩），按「只引导」定位决定是否纳入 v1 声明
- [ ] **注册表残留**（RegistryInspector）：只读扫描，验证「只读」承诺（无任何写路径），决定纳入 v1 声明或标注实验性
- [ ] 三项决定写入 `docs/goals.md` Phase 1 勾选与 README「范围」段：转正者列出验收记录锚点，排除者写明排除原因
- [ ] 任何能力转正前若发现行为缺陷：当场修复（附回归）或标记排除，不得带缺陷转正

**边界：** 本票不新增功能、不扩大任何能力的写路径。
