# 05 前端选型与主界面原型

Type: prototype
Status: closed

## Question

PWA 前端的技术选型与主界面形态（HITL，产出可反应的原型）：

1. **栈**：无构建 vanilla JS + Web Components？Preact/Lit？约束："更简单"是本次重构的动因，前端不应引入新的重依赖与构建链；中文文案；manifest + SW 可安装、离线可用（SW 缓存壳资源）。
2. **观感**：Fluent 风格延续还是自由发挥。
3. **主界面原型**：规则行勾选（含安全性说明展示、默认勾选策略）→ 扫描进度 → 预览确认（将删除什么/每类多少）→ 执行 → 结果。对照现 `MainWindow` 的信息架构出 HTML 原型供用户反应。

产出：选型决策 + 原型资产链接到本工单。

## Answer

**已落定（2026-08-31 用户选定）：**

1. **栈：无构建 vanilla JS + 原生 Web Components**。零工具链零依赖（原型即证据：单文件含状态机、多视图、URL 参数切换）；中文文案直出；manifest + SW 缓存壳资源在实施阶段补齐。
2. **主界面形态：变体 C「分类聚合」**。左栏（环形可释放汇总 + 统计 + 隔离区/历史/工具箱/启动项/设置导航）+ 右侧按类别折叠卡片（展开进规则行：勾选、风险/管理员/未验证徽标、安全说明、文件数与大小）+ 底部扫描条 + 确认走右滑抽屉（按类别汇总 → 确认移入隔离区 → 结果含批次号与跳过数）。
3. 默认勾选策略沿用：低风险 + 已验证默认勾选；未验证项标记「未验证·默认不勾选」且不勾选。

A（向导式）/ B（工作台）落选；原型保留于 `.scratch/pwa-refactor/prototype/` 作实施参照，不进 main。
