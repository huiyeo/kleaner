## 已锁定的决策

| 决策点 | 结论 |
|---|---|
| 任务顺序 | 语言规范先定 → UI 重构收尾提交 → 规范全量落地 → 优化盘点 |
| UI"完成"标准 | 统一档：收尾当前 8 文件改动 + 视觉走查 + 样式上收（7 个工具窗口零私有样式；MainWindow 标题栏专属样式保留窗口内并注释标明） |
| 未提交改动处置 | 先静态审查样式 Key → Release 构建 → 逐窗口截图走查 → 修复后一次性提交 |
| 项目语言范围 | 提交信息规范 + UI 文案走 S 通道 + .editorconfig/分析器/注释语言；文档语言暂不约定 |
| 提交信息语言 | 英文 type/scope + 中文 subject（conventional commits） |
| 注释语言 | 统一中文 |
| 分析器严格度 | 警告级，不设 TreatWarningsAsErrors，存量清单化观察 |
| 优化盘点维度 | 架构（模块边界/依赖方向）+ 测试（Executor/SpecialOps/App VM 覆盖缺口） |
| 产出形式 | 盘点报告 → 人工勾选 → 工单落 `.scratch/improvements/issues/`（沿用三张工单格式） |
