# 03: 为启动项管理补充自动化测试

**What to build:** 启动项管理（禁用/还原/备份记录）目前零自动化测试，唯一自检（CLI startup-test）会写真实注册表与启动文件夹，CI 不可跑。本工单把核心逻辑纳入 xunit 覆盖，测试不触碰真实注册表与真实启动目录。

前置小重构：启动项管理的注册表访问与启动目录枚举改为可注入（缺省仍走真实实现），现有调用点（无参构造）保持兼容；文件型操作的备份目录与历史写入已可注入。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 文件型启动项：禁用（文件移入备份目录、备份记录写入、历史审计 startup-disable）→ 还原（文件移回、记录删除、历史审计 startup-restore）往返一致
- [ ] 注册表型（HKCU）启动项：禁用先写备份记录再删值；删值失败时备份记录回滚
- [ ] 错误路径：目标位置被占用不覆盖并抛异常、备份文件丢失、备份目录同名冲突
- [ ] HKLM/提权路径（reg.exe runas）不纳入单元测试，测试中注明排除原因
- [ ] 测试全程不触碰真实注册表与真实启动目录，CI 可安全运行
