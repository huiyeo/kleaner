# 02: 在途改动收尾：清理调试输出并接通启动项选择交互

**What to build:** 上一轮在途开发遗留的两处半成品收尾，让空间分析（treemap）与启动项管理两个功能可对外展示、可提交。

一、空间分析界面不再输出格式为「[诊断 host=… canvas=… rects=…]」的调试残留文案，正常的界面状态反馈保留。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent
