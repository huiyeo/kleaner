# 01: CLI 扫描与清理排除隔离区自身

**What to build:** CLI 的 `scan` 与 `clean` 命令与 GUI 保持一致，把隔离区目录从扫描范围里排除，避免"把已隔离的文件再次计入可清理项"。隔离区位置解析规则与 GUI 一致：优先读用户设置里的隔离区位置，缺省回退到剩余空间最大的非系统盘。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] `scan` 的候选清单不包含当前隔离区目录下的任何文件
- [ ] `clean` 的计划与执行同样排除隔离区
- [ ] 隔离区位置解析与 GUI 一致（设置覆盖优先，缺省非系统盘剩余空间最大）
- [ ] 排除判断按路径段边界匹配（`D:\KleanerQuarantine` 不应误伤 `D:\KleanerQuarantine2`），而非裸前缀匹配
- [ ] 扫描排除行为有自动化用例覆盖；现有测试保持绿色
