# 14: 操作历史哈希链（篡改可发现）

**What to build:** 依据 ADR-0002 的结论，凭据来源认证在同权限攻击者模型下不可达成；对「强制审计」北极星真正有效的强化是让 `history.jsonl` 本身具备**篡改可发现性**：每条追加记录携带前一条记录内容的哈希，形成可校验的链条。历史窗口展示与 `RecoverPendingAudit` 等读取路径在校验失败时明确提示「历史完整性校验失败」（含首个断裂位置），不得静默跳过或伪装为完整。

**Blocked by:** None（工单 10 已收口；本票是其后续强化）。测试仅使用注入的临时 history 路径，不得触真实历史文件。

**Status:** ready-for-agent

- [ ] `HistoryManager` 追加路径写入链哈希（记录版本升级，旧版无链记录可读但标注为未链段）
- [ ] `Recent` / 历史窗口展示时校验链条，断裂时给出明确提示与断裂位置，不伪装完整
- [ ] 补记（`AppendOnce` / 汇总补记）路径同样校验并在断裂时按项目惯例 fail-closed 处理
- [ ] xunit 覆盖：正常链、删除中间记录、截断尾部、插入伪造记录、重放未链旧记录
- [ ] UI 文案进 `Strings.zh-CN.json`；同步 `docs/deletion-path.md`
- [ ] 文档与 UI 措辞不得宣称「防篡改」：哈希链是检测不是预防，攻击者理论上可重算整链

**边界（承 ADR-0002）：** 本票不改变「同权限本地进程可伪造一切本机数据」的威胁模型结论；它提高篡改成本并让删改对用户可见。越权级方案（受控签名链、提权服务、TPM 锚定）超出本产品范围。
